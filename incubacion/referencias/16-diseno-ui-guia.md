## UI vs UX

- **UI (User Interface):** elementos visuales e interacción — botones, textos, imágenes, controles, colores, layout
- **UX (User Experience):** experiencia general del usuario al navegar el producto

> Un diseño hermoso con interfaz torpe arruina la experiencia. Una buena UX con mal UI la vuelve desagradable. Deben estar alineados.

---

## Actividades sugeridas

### 1. Buscar inspiración visual
Explorar Behance, Dribbble, Figma Community para identificar estilos, layouts, componentes y patrones.

### 2. Definir identidad visual básica
Antes de diseñar pantallas:
- Colores principales
- Tipografías
- Espaciados
- Estilos de botones, inputs, cards, estados

### 3. Diseñar pantallas principales del MVP
Vistas clave: inicio, conexión de wallet, dashboard, acción principal, confirmaciones, estados de carga y errores.

### 4. Crear prototipo navegable
Conectar pantallas en Figma para simular el recorrido del usuario.

### 5. Validar diseño visual
Compartir con usuarios, mentores, equipo. Feedback sobre jerarquía visual, textos, navegación, estados.

> 💡 El diseño UI no es solo "que se vea bien". Ayuda al usuario a entender qué puede hacer, dónde interactuar y qué está pasando. Reduce fricción, mejora confianza.

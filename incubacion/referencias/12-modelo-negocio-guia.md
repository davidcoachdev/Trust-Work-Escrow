## Modelos de Negocio en Web3

| Modelo | Descripción |
|--------|-------------|
| **Fees por transacción** | Pequeño % por cada transacción (ej: marketplace NFT) |
| **Suscripción mediante NFTs** | NFT como ticket de suscripción mensual/anual |
| **Freemium / Premium** | Funcionalidades limitadas vs versión completa |
| **Community funding** | Token de gobernanza + SNS para financiamiento comunitario |
| **Tokenización** | Token con utilidad que genera economía alrededor del proyecto |

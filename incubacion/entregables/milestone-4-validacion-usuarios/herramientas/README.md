## 🔄 Flujo de uso (recomendado)

```
1. Leer 02 (mercado)        → definir segmento: freelancer crypto-native
2. Difundir con 05 / 06      → reclutar entrevistados y respuestas
3. Entrevistar con 01        → 5-8 charlas 1:1, anotar en template
4. Lanzar encuesta 04        → 20-50 respuestas cuantitativas
5. Ponderar con 03           → ranking comisiones/velocidad/confianza/disputas
6. Cruzar A/B/C (migración)  → responder: ¿motor = ahorro o confianza?
7. Volcar al plan principal  → sección "Resultados de Encuesta" + reporte final
```

---

## 🎯 Pregunta del programa que estos archivos ayudan a responder

> Si un freelancer ya usa Upwork/Fiverr y paga comisión alta, ¿qué tendría que pasar para migrar a Trust Work Escrow? ¿El ahorro alcanza o pesa más la confianza/escrow?

La respuesta se construye con:
- **Q6 de la encuesta (04)** y **A2.6 de entrevistas (01)** → ranking de prioridades.
- **Q8 de la encuesta (04)** y **A3.9/A3.10 (01)** → categoría de migración A/B/C.
- **Ponderación (03)** → cuantifica si confianza ≥ ahorro.
